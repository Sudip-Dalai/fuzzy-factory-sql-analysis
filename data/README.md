# Data

The CSV files are not stored in this repo (the largest is over 40 MB).

Download the **Toy Store E-Commerce Database** (Maven Fuzzy Factory) from Maven Analytics:
https://mavenanalytics.io/data-playground/toy-store-e-commerce-database

Check the license terms on that page before reusing the data.

Files used: `products.csv`, `website_sessions.csv`, `orders.csv`, `order_items.csv`, `order_item_refunds.csv`.
`website_pageviews.csv` (about 1.2M rows) is not used in this project.
